# Dikdasmen

Selamat datang di **Dikdasmen** - sebuah project web yang modern dan responsif.

## 📋 Deskripsi

Dikdasmen adalah sebuah aplikasi web yang dibangun dengan HTML untuk memberikan pengalaman pengguna yang optimal. Project ini menyediakan solusi web yang dapat diakses dan mudah digunakan.

## 🛠️ Teknologi yang Digunakan

- **HTML5** - Struktur dan markup halaman web
- **CSS** - Styling dan desain responsif
- **JavaScript** - Interaktivitas dan fungsionalitas dinamis

## 📁 Struktur Project

```
Dikdasmen/
├── index.html          # Halaman utama
├── styles/             # File CSS
├── scripts/            # File JavaScript
├── assets/             # Gambar dan resource lainnya
└── README.md          # Dokumentasi project
```

## 🚀 Cara Memulai

1. **Clone Repository**
   ```bash
   git clone https://github.com/MFSA01/Dikdasmen.git
   cd Dikdasmen
   ```

2. **Buka di Browser**
   - Buka file `index.html` langsung di browser Anda
   - Atau gunakan Live Server extension jika menggunakan editor seperti VS Code

3. **Develop**
   - Edit file HTML, CSS, dan JavaScript sesuai kebutuhan
   - Refresh browser untuk melihat perubahan
